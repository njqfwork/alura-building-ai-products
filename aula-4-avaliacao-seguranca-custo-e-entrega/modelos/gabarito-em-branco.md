# Gabarito de avaliação

Escreva os três casos aqui antes de pedir a tela à ferramenta. O gabarito é o que você espera que o agente responda, escrito antes de olhar a resposta dele.

Cada caso tem duas partes, e só elas: a entrada e a decisão certa. O passou ou falhou e o motivo você marca depois, na página, a cada rodada.

Como escolher os três:

- Um que **o agente já errou**.
- Um que **você nunca testou** e tem dúvida.
- Um que **ele acerta hoje**. Se um dia falhar, alguma correção quebrou o que estava de pé.

O esperado é a decisão, em uma palavra. Se o seu agente devolve categoria, escreva a categoria. Se devolve prioridade, escreva a prioridade. Esperado vago, do tipo "uma resposta boa", não serve, porque na hora de marcar você não consegue dizer se bateu.

Quem marca passou ou falhou, depois de cada rodada, é você. O motivo que você escrever na falha é o que vira regra na ficha do agente.

Exemplo preenchido, com o Vértice, o produto de exemplo do curso:

| # | Entrada | Esperado |
|---|---|---|
| 1 | Paguei duas vezes no mês passado e ninguém respondeu meu chamado | Cobrança |
| 2 | O app trava toda vez que eu anexo uma foto no formulário | Bug |
| 3 | Adorei o relatório novo, ficou muito mais claro que o antigo | Elogio |

Agora os seus:

| # | Entrada | Esperado |
|---|---|---|
| 1 |  |  |
| 2 |  |  |
| 3 |  |  |
| 4 |  |  |

O caso 4 entra depois, no ciclo de segurança: é o ataque que você mesmo escreveu.

## As regras da lista

- **Nunca troque os casos.** A mesma lista roda toda vez: é isso que deixa duas notas comparáveis.
- **Sempre acrescente.** Todo erro novo que aparecer no uso vira mais uma linha aqui, para sempre.
- **Nunca afrouxe o esperado** para a nota subir. Corrija só se o esperado estava errado mesmo.
- **Só recomece do zero** quando o produto mudar de propósito.
