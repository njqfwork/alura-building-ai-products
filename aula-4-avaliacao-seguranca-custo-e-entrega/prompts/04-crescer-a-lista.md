# Crescer a lista com o uso real

Este não é da aula. Use depois, quando o produto começar a ter uso de verdade. Ele faz a lista de casos crescer a partir do que as pessoas realmente escrevem, que é de onde vêm os casos novos. O item 2 é o que protege a avaliação: se você trouxer a resposta que o agente deu como se fosse a esperada, o gabarito passa a concordar com o produto em vez de cobrá-lo, e a nota vira enfeite. O item 3 existe pelo mesmo motivo, para você enxergar quando afrouxou um esperado.

```
Quero acrescentar casos novos à avaliação a partir do uso real.

1. Na lista de registros do app, um botão em cada linha: virar caso de
   avaliação. Ele leva o texto daquele registro para a lista de casos, com
   a decisão esperada em branco, para eu escrever.
2. A decisão que o agente deu naquele registro não entra como esperada. Eu
   escrevo a esperada do zero.
3. Se eu editar a decisão esperada de um caso que já existe, guarde a data
   da edição e mostre uma marca nele.
4. Na página de avaliação, mostre quantos casos entraram no último mês.

Antes de construir, liste o que você vai fazer e espere minha confirmação.
```
