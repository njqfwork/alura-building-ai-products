# Conferir as chaves antes do GitHub

Cole na ferramenta de construção antes do primeiro envio. Ele confere se alguma chave, senha ou token iria junto para o GitHub, e não envia nada. Se ele apontar algo, peça para mover para os Secrets. Depois, siga o passo a passo do [guia da aula](../guia-da-aula-3.md#1-o-código-no-github).

```
Vou enviar este projeto para um repositório no GitHub. Antes disso, confira:
1. Se alguma chave, senha ou token está escrito direto no código ou em algum
   arquivo que vai junto.
2. Se o arquivo .gitignore impede que segredos, arquivos de ambiente e dados
   do banco sejam enviados.
Me diga o que encontrou e o que ajustou. Não envie nada ainda.
```
