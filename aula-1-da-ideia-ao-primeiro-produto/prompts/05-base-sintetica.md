# Gerar a sua base sintética

Cole no seu chat de IA. Você recebe um CSV com 40 linhas, que vai para o banco na Aula 2. Uma categoria tem o dobro das outras para a contagem mostrar alguma coisa: base distribuída por igual não revela nada. Se o seu produto não recebe textos de clientes, troque por 40 casos do que ele recebe, como 40 descrições de negócio com problema ou 40 ideias de produto. Nenhum dado real, em nenhuma aula.

```
Gere 40 feedbacks fictícios de clientes de [seu produto].
Português informal, frases curtas, como mensagens reais.
Cada feedback tem uma categoria: [suas 5 categorias].
[uma categoria] deve ter o dobro de feedbacks de cada outra.
Nenhuma pessoa real. Formato CSV com as colunas texto,categoria.
```
